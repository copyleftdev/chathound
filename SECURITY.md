# Security Policy

## Supported Versions
The latest release on `main`.

## Reporting a Vulnerability
Please open a private security advisory via GitHub's "Report a vulnerability"
button on the Security tab, or email the repo owner via their GitHub profile.
Do not open public issues for vulnerabilities.

## Scope
chathound is a read-only client for a public HTTP endpoint. Still: report
anything that could cause unintended request volume against third parties.
